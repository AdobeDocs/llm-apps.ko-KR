# 콘텐츠 모델 및 용어

## 컨텐츠 유형

### 튜토리얼

하나의 완전한 성공적인 여정을 통해 새로운 사용자에게 설명합니다.

- 결과 및 사전 요구 사항을 기술합니다.
- 하나의 샘플 앱과 하나의 시퀀스를 사용합니다.
- 각 단계에서 필요한 개념만 설명합니다.
- 작업 결과로 끝내고 다음 단계를 지웁니다.

기본 자습서: `help/guides/create-app.md`.

### 개념

프로시저나 필드 카탈로그가 되지 않고 부품이 어떻게 관련되는지를 설명합니다.

- 정신 모델과 소유권 경계에 초점을 맞추십시오.
- 이해를 향상시킬 때 작은 다이어그램을 사용하십시오.
- 튜토리얼, 사용 방법 안내서 및 참조에 대한 링크입니다.

### 방법 안내서

정보를 받은 사용자가 하나의 작업을 완료할 수 있도록 지원합니다.

- 원하는 결과로 시작합니다.
- 작업과 관련된 필수 구성 요소만 포함합니다.
- 하나의 권장 경로를 선호합니다.
- 전체 필드에 대한 참조에 대한 링크입니다.

예: 작업을 처음부터 만들고, 위젯을 사용자 정의하고, EDS 프로젝트를 가져오고, 배포하고, 테스트합니다.

### 참조

사용자가 작업하는 동안 참조할 수 있는 사실 정보를 제공합니다.

- 제품 또는 코드 표면별로 구성합니다.
- 모든 필드, 계약, 명령, 제한 및 상태를 정확하게 정의합니다.
- 튜토리얼 내레이션 및 반복되는 예제는 피하십시오.

### 문제 해결

관찰할 수 있는 증상에서 시작합니다.

- 가능한 원인을 설명합니다.
- 안전한 진단 단계를 제공합니다.
- 사용자에게 자격 증명 또는 중요한 로그를 공개하도록 요청하지 마십시오.

## 표준 용어

- **Adobe LLM 앱** — 처음 언급할 때 전체 제품 이름입니다.
- **LLM 앱** - 제품에서 관리하는 앱 1개.
- **내 앱 빌드** — 앱 만들기 대화 상자의 UI 섹션.
- **내 앱을 자동으로 빌드** — 정확한 확인란 레이블.
- **작업** — LLM 플랫폼에 노출된 기능입니다.
- **작업 메타데이터** — LLM 앱에서 저장된 이름, 설명, 스키마, 주석, 가시성 및 위젯 구성입니다.
- **작업 처리기** — 처리기 저장소의 서버측 함수입니다.
- **처리기 저장소** — 처리기와 테스트가 포함된 저장소입니다. 해당 컨트롤을 설명하는 경우에만 UI 레이블 **Boilerplate 저장소**&#x200B;를 사용하십시오.
- **EDS 저장소** — 위젯 블록과 콘텐츠가 포함된 저장소입니다.
- **위젯** — LLM 플랫폼에서 렌더링되는 시각적 응답입니다.
- **MCP 서버 URL** — 배포된 끝점이 LLM 플랫폼에 등록되었습니다.
- **ChatGPT 플러그인** — MCP 서버 URL에서 만든 ChatGPT 통합입니다.
- **스테이징** 및 **프로덕션** — 배포 환경.

MCP 프로토콜 세부 사항을 설명하지 않는 한 사용자 관련 프로덕션에서 &quot;tool&quot;과 &quot;action&quot; 간을 전환하지 마십시오.

이 제품은 플랫폼에 구애받지 않습니다 : MCP 서버는 ChatGPT뿐만 아니라 지원되는 모든 LLM 플랫폼과 작동합니다. 일반 청구 또는 설명 청구에 대해 &quot;ChatGPT&quot;(또는 이와 유사한)와 같은 지원되는 LLM 플랫폼을 사용하십시오. 현재 ChatGPT와 관련된 콘텐츠에서만 ChatGPT의 이름을 지정합니다(ChatGPT 안내서의 테스트, 직접 교차 링크, ChatGPT와 관련된 참조 또는 문제 해결 콘텐츠).

## 권장 판독기 여정

1. 개요 및 사전 요구 사항.
2. 앱을 자동으로 만듭니다.
3. 생성된 작업을 검토합니다.
4. Stage에 배포하고 ChatGPT 플러그인을 테스트합니다.
5. 생성된 핸들러 및 위젯을 사용자 정의합니다.
6. 사용자 지정된 앱을 프로덕션에 배포합니다.

작업을 처음부터 새로 만들고 EDS 프로젝트를 가져오는 것은 기본 첫 실행 여정이 아닌 고급 분기입니다.
