# 작업 및 위젯 필드 {#action-widget-configuration}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]이(가) 현재 Beta에 있습니다.
>
>여기에 표시된 기능, 워크플로우 및 UI가 반드시 제품의 최종 상태를 나타내지는 않습니다. Beta에 참여하려면 llm-apps-beta@adobe.com으로 이메일을 보내십시오.

이 페이지를 사용하여 작업 편집기에서 필드를 조회합니다. 만들기 단계는 [처음부터 작업 만들기](/help/guides/create-action.md)를 참조하십시오.

## 설정 찾기

**[!UICONTROL 새 작업 만들기]** 대화 상자에 **[!UICONTROL 작업]** 및 **[!UICONTROL 위젯 메타데이터]** 탭이 있습니다.

생성 후 저장된 작업 편집기에서는 다음 세 가지 탭을 사용합니다.

| 탭 | 설정 |
|---|---|
| **[!UICONTROL LLM 위젯 세부 정보]** | 위젯 유형, 샌드박스 도메인, 위젯 설명, 템플릿 URL 및 CSP |
| **[!UICONTROL 작업 세부 정보]** | 주석, 호출 상태 텍스트 및 가시성을 포함한 코드 식별자, 설명, 입력 매개 변수 및 **[!UICONTROL LLM 설정]** |
| **[!UICONTROL 분석]** | 사용자 의도 수집 및 지침 |

편집 내용을 저장하려면 **[!UICONTROL 변경 내용 저장]**&#x200B;을 선택합니다. 검토 대기 중인 생성된 작업은 대신 **[!UICONTROL 검토됨으로 표시]**&#x200B;되며, 이는 생성된 끌어오기 요청도 처리합니다.

## 작업 매개 변수

입력 매개 변수는 LLM 플랫폼이 작업 핸들러로 보내는 값입니다. 이 모델은 사용자 메시지에서 값을 추출하여 구성된 매개변수에 매핑합니다.

| 속성 | 설명 |
|----------|-------------|
| **이름** | 매개 변수 식별자(예: `category`, `query`) |
| **유형** | `String`, `Number`, `Integer` 또는 `Boolean` |
| **설명** | 사람이 읽을 수 있는 설명 — LLM 플랫폼은 설명을 사용하여 올바른 값을 추출합니다 |
| **필수** | 이 옵션이 선택되어 있으면 작업을 호출하기 전에 모델이 이 매개변수를 제공해야 합니다 |

### 파일 매개 변수

파일 매개 변수는 작업 편집기에 구성된 입력 필드 이름입니다. 사용자가 파일을 업로드할 때 호스트는 일반적으로 `download_url` 및 `file_id`을(를) 포함하여 해당 인수에 대한 파일 개체를 제공합니다.

## 메타데이터 필드

### 기본 정보

| 필드 | 필수 | 설명 |
|-------|----------|-------------|
| **작업 이름** | 예 | 작업의 표시 이름(예: *제품 검색*) |
| **설명** | 예 | 작업이 수행하는 작업에 대한 설명 - LLM 플랫폼은 설명을 사용하여 작업을 호출할 시기를 결정합니다 |

만들기 대화 상자에서 작업 이름에서 파생된 변경할 수 없는 **코드 식별자**&#x200B;을 미리 봅니다. 앱 내에서 고유하며 소문자로 시작하고 소문자, 숫자, 하이픈 또는 밑줄을 사용하여 최대 63자를 포함합니다. 작업을 처리기 저장소의 `actions/<code-identifier>/index.js`에 매핑합니다.

### 주석

작업의 동작을 설명하는 선택적 힌트입니다.

| 주석 | 설명 |
|------------|-------------|
| **파괴적 힌트** | 작업은 데이터를 삭제하거나 덮어쓸 수 있습니다 |
| **Idempotent(동일한 인수 = 추가 효과 없음)** | 동일한 요청을 반복해도 환경에 추가적인 영향을 주지 않습니다. 반복되는 요청이 반드시 동일한 데이터를 반환하지는 않습니다 |
| **Open World 힌트** | 작업이 외부 시스템과 상호 작용합니다 |
| **읽기 전용 힌트** | 작업은 데이터만 읽고 쓰지는 않습니다. |

### OpenAI 메타데이터

| 필드 | 최대 길이 | 설명 |
|-------|------------|-------------|
| **상태 텍스트 호출** | 64자 | 작업이 실행되는 동안 LLM 플랫폼에 표시되는 메시지(예: *제품 로드 중...*) |
| **상태 텍스트를 호출했습니다** | 64자 | 작업이 완료된 후 표시되는 메시지(예: *제품을 로드함..*) |
| **위젯 설명** | 512자 | `_meta["openai/widgetDescription"]`에 매핑합니다. 모델에 대해 렌더링된 구성 요소를 요약하고 반복되는 내레이션을 줄입니다. |

작업 설명은 모델이 작업을 선택할 시기를 제어합니다. 위젯 설명은 구성 요소가 렌더링 후 표시되는 내용을 설명합니다.

### 가시성

작업을 켜거나 끄려면 앱 페이지에서 **[!UICONTROL 가시성]** 스위치를 사용하십시오. 스위치는 다음 배포에 작업이 포함되는지 여부를 제어합니다. 작업 편집기에는 별도의 온/오프 스위치가 없습니다.

다음 작업 편집기 설정은 앱 수준의 켜기/끄기 상태가 아닌 모델 및 위젯 노출을 제어합니다.

| 토글 | 설명 |
|--------|-------------|
| **AI 모델에 표시** | 대화하는 동안 AI 모델이 작업을 호출할 수 있습니다 |
| **앱 표면에 위젯으로 표시** | 이 작업은 앱에서 시각적 위젯을 렌더링합니다 |

모델 및 위젯 노출 설정은 위젯 유형 선택을 대체하지 않습니다.

### 분석

| 필드 | 설명 |
|-------|-------------|
| **사용자 의도 수집** | 기본적으로 활성화되어 있습니다. Analytics에 대한 작업을 유도한 목표에 대한 익명화된 요약을 요청합니다 |
| **사용자 의도 설명** | 요약을 요청하는 데 사용되는 지침(최대 2,000자). 기본값은 개인적이고 민감한 정보를 제외합니다. 개인정보 처리방침에 대한 모든 사용자 정의 검토 |

## 위젯 필드

### 위젯 정보

| 필드 | 설명 |
|-------|-------------|
| **유형/위젯 유형** | 만들기 대화 상자에서 **[!UICONTROL Edge Delivery Services 블록]** 또는 **[!UICONTROL 위젯 없음]**&#x200B;을 선택합니다. 저장된 편집기에서 텍스트 전용 선택 항목의 레이블을 지정합니다. **[!UICONTROL 대화형 UI 없음]** |
| **위젯 도메인** | 호스트에서 사용하는 샌드박스 원본. UI는 앱 제출에 필요하고 앱별로 고유함을 식별합니다. EDS 페이지의 **위젯 URL**&#x200B;과(와) 별개입니다. |
| **테두리를 선호함** | 경계 컨테이너를 요청합니다. 렌더링은 호스트에 따라 다릅니다. 만들기 대화 상자에서 사용할 수 있습니다. |

### 템플릿 URL

| 필드 | 설명 |
|-------|-------------|
| **[!UICONTROL 스크립트 URL]** | EDS `scripts/aem-embed.js` 진입점의 HTTPS URL입니다. 동일한 EDS 프로젝트의 작업 간에 공유됨 |
| **위젯 URL** | 작업에서 렌더링된 EDS 페이지의 HTTPS URL입니다. 생성된 작업은 URL을 자동으로 구성합니다. |

## CSP 구성

컨텐츠 보안 정책은 위젯 iframe이 연결할 수 있는 외부 도메인을 제어합니다. 모든 외부 도메인은 명시적으로 허용 목록에추가된여야 합니다.

| 지침 | 설명 |
|-----------|-------------|
| **리소스 도메인** | 정적 에셋용 도메인 — 이미지, 글꼴, 스크립트, 스타일 |
| **도메인 연결** | `fetch`, `XHR` 또는 `WebSocket`을(를) 통해 위젯이 연결할 수 있는 도메인 |
| **프레임 도메인** | 중첩된 iframe에 허용된 원본. 더 엄격한 앱 검토를 트리거합니다. |
| **도메인 리디렉션** | `openExternal`개의 리디렉션 링크에 대한 신뢰할 수 있는 대상([!DNL ChatGPT]별) |
| **기본 URI 도메인** | `base-uri` CSP 지시문(MCP 앱 SDK 전용, [!DNL ChatGPT] 제외) |

## 권한

위젯 권한은 하드웨어 및 브라우저 API에 대한 액세스를 제어합니다. 권한은 iframe 권한 정책에 매핑됩니다.

권한 컨트롤은 만들기 대화 상자의 **[!UICONTROL 권한(MCP 특정)]** 아래에 나타납니다. 위젯에 필요한 기능만 부여합니다. 호스트 지원 및 사용자 동의도 적용됩니다.

| 권한 | 설명 |
|------------|-------------|
| **카메라** | 장치 카메라 액세스 |
| **마이크** | 장치 마이크 액세스 |
| **지리적 위치** | 사용자 위치 액세스 |
| **클립보드** | 클립보드에서 읽기 또는 쓰기 |
