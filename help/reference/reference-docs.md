# 참조 자료 {#reference-material}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]이(가) 현재 Beta에 있습니다.
>
>여기에 표시된 기능, 워크플로우 및 UI가 반드시 제품의 최종 상태를 나타내지는 않습니다. Beta에 참여하려면 llm-apps-beta@adobe.com으로 이메일을 보내십시오.

이 섹션에서는 [!DNL Adobe LLM Apps] UI의 작업 구성에 대한 필드 수준 참조를 제공합니다.

## 작업 매개 변수

입력 매개 변수는 LLM 플랫폼([!DNL ChatGPT], Claude)이 작업 처리기로 보내는 값입니다. 이 모델은 사용자 메시지에서 이러한 필드를 추출하여 이러한 필드에 자동으로 매핑합니다.

| 속성 | 설명 |
|----------|-------------|
| **이름** | 매개 변수 식별자(예: `category`, `query`) |
| **유형** | `String`, `Number`, `Integer` 또는 `Boolean` |
| **설명** | 사람이 읽을 수 있는 설명 — LLM 플랫폼은 이를 사용하여 올바른 값을 추출합니다 |
| **필수** | 이 옵션이 선택되어 있으면 작업을 호출하기 전에 모델이 이 매개변수를 제공해야 합니다 |

### 파일 매개 변수

파일 매개 변수에는 `download_url` 및 `file_id` 속성이 있는 파일 개체가 있습니다. 사용자가 대화에서 파일을 업로드할 때 파일 데이터를 수신할 입력 필드 이름을 정의합니다.

## 메타데이터 필드

### 기본 정보

| 필드 | 필수 | 설명 |
|-------|----------|-------------|
| **작업 이름** | 예 | 작업 식별자(예: *제품 검색*) |
| **설명** | 예 | 작업이 수행하는 작업에 대한 설명 — LLM 플랫폼은 이를 사용하여 호출 시기를 결정합니다 |

### 주석

작업의 동작을 설명하는 선택적 힌트입니다.

| 주석 | 설명 |
|------------|-------------|
| **파괴적 힌트** | 이 작업은 데이터를 수정하거나 삭제합니다 |
| **Idempotent** | 동일한 인수로 작업을 여러 번 호출해도 결과는 동일합니다 |
| **Open World 힌트** | 작업이 외부 시스템과 상호 작용합니다 |
| **읽기 전용 힌트** | 작업은 데이터만 읽고 쓰지는 않습니다. |

### OpenAI 메타데이터

| 필드 | 최대 길이 | 설명 |
|-------|------------|-------------|
| **상태 텍스트 호출** | 64자 | 작업이 실행되는 동안 LLM 플랫폼에 메시지가 표시됩니다(예: *제품 로드 중...* ). |
| **상태 텍스트를 호출했습니다** | 64자 | 작업이 완료된 후 표시되는 메시지(예: *로드된 제품 ...* ) |

### 가시성

| 토글 | 설명 |
|--------|-------------|
| **AI 모델에 표시** | 대화하는 동안 AI 모델이 작업을 호출할 수 있습니다 |
| **앱 표면에 위젯으로 표시** | 이 작업은 앱에서 시각적 위젯을 렌더링합니다 |

### 위젯 정보

| 필드 | 설명 |
|-------|-------------|
| **유형** | 위젯 기술 — 현재 **[!UICONTROL EDS]** |
| **위젯 도메인(샌드박스 원본)** | 위젯이 호스팅되는 원본입니다. 앱별로 고유해야 합니다. |
| **테두리를 선호함** | 선택하면 LLM 플랫폼의 경계 카드 내에서 위젯이 렌더링됩니다 |

### 템플릿 URL

| 필드 | 설명 |
|-------|-------------|
| **[!UICONTROL 스크립트 URL]** | 진입점 스크립트 — `https://main--<repo>--<owner>.aem.live/scripts/aem-embed.js`. 모든 작업에서 공유됨 |
| **위젯 포함 URL** | 이 작업의 EDS 페이지 — `https://main--<repo>--<owner>.aem.live/eds-widgets/<action-name>`. 작업당 고유 |

## CSP 구성

컨텐츠 보안 정책은 위젯 iframe이 연결할 수 있는 외부 도메인을 제어합니다. 모든 외부 도메인은 명시적으로 허용 목록에추가된여야 합니다.

| 지침 | 설명 |
|-----------|-------------|
| **리소스 도메인** | 정적 에셋용 도메인 — 이미지, 글꼴, 스크립트, 스타일 |
| **도메인 연결** | `fetch`, `XHR` 또는 `WebSocket`을(를) 통해 위젯이 연결할 수 있는 도메인 |
| **프레임 도메인** | 중첩된 iframe에 허용된 원본. 더 엄격한 앱 검토를 트리거합니다. |
| **도메인 리디렉션** | `openExternal`개의 리디렉션 링크에 대한 신뢰할 수 있는 대상([!DNL ChatGPT]별) |
| **기본 URI 도메인** | `base-uri` CSP 지시문(MCP 앱 SDK 전용, [!DNL ChatGPT] 제외) |

## 권한

위젯에서 액세스할 수 있는 하드웨어 및 브라우저 API입니다. 이는 iframe 권한 정책에 매핑됩니다.

| 권한 | 설명 |
|------------|-------------|
| **카메라** | 장치 카메라 액세스 |
| **마이크** | 장치 마이크 액세스 |
| **지리적 위치** | 사용자 위치 액세스 |
| **클립보드** | 클립보드에서 읽기 또는 쓰기 |
