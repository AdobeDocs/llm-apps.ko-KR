# 작업 만들기

이 안내서에서는 [!DNL LLM Apps] UI에서 작업을 정의하는 방법을 안내합니다. 작업의 정의와 작동 방식에 대한 배경은 [핵심 개념](/help/overview/overview.md#actions)을 참조하세요.

## 작업 페이지를 엽니다.

왼쪽 사이드바에서 **[!UICONTROL 작업]**(으)로 이동하거나 앱 세부 정보 페이지에서 **작업으로 이동**&#x200B;을 클릭합니다. 작업이 아직 존재하지 않으면 페이지에 빈 상태가 표시됩니다.

![작업 페이지 — 아직 작업이 없습니다](/help/assets/guide-create-action/actions-empty.png)

전체 화면 대화 상자를 열려면 **+ 작업 만들기**&#x200B;를 클릭하십시오.

## 작업 카드

각 작업은 다음을 보여주는 카드로 표시됩니다.

- 작업 **이름** 및 **설명**
- **위젯 미리 보기 이미지** — 위젯에서 자동으로 생성되며 LLM 플랫폼 내에서 작업 출력이 어떻게 표시되는지 보여 줍니다.
- **배지**: 위젯 유형(**[!UICONTROL EDS]**), 배포 상태(**배포되지 않음**, **스테이징에 배포됨**, **프로덕션에 배포됨**), 마지막 배포 이후 작업이 수정된 경우 **변경 내용이 배포되지 않음** 및 매개 변수 개수
- **가시성** 전환 — 다시 배포하지 않고 라이브 끝점에서 작업을 활성화하거나 비활성화합니다.
- 작업 편집기를 열기 위한 오른쪽 상단의 **검토** 링크

![작업 페이지 — 작업 카드](/help/assets/guide-create-action/action-card.png)

마지막 배포 이후 하나 이상의 작업이 수정되면 **배포 필요** 배너가 [작업] 페이지의 맨 위에 나타납니다. 앱을 재배포하여 변경 사항을 적용합니다.

## 작업 탭

대화 상자에는 **작업** 및 **[!UICONTROL 위젯 메타데이터]**&#x200B;의 두 가지 탭이 있습니다.

### 기본 정보

![작업 만들기 — 기본 정보](/help/assets/guide-create-action/action-basic-info.png)

- **작업 이름**(필수) — 작업의 식별자입니다(예: *제품 검색*).
- **설명**(필수) - 작업이 수행하는 작업에 대한 명확한 설명. LLM 플랫폼은 이 함수를 사용하여 작업을 호출할 시기를 결정합니다. 예를 들어 *키워드로 제품 카탈로그를 검색하십시오. 이름, 범주, 이미지 및 가격과 일치하는 제품을 반환합니다.*
- **주석** — 작업의 동작을 설명하는 선택적 힌트입니다.

  | 주석 | 설명 |
  |-----------|-------------|
  | **파괴적 힌트** | 이 작업은 데이터를 수정하거나 삭제합니다 |
  | **Idempotent** | 동일한 인수로 작업을 여러 번 호출하면 동일한 결과가 생성됩니다 |
  | **Open World 힌트** | 작업이 외부 시스템과 상호 작용합니다 |
  | **읽기 전용 힌트** | 작업은 데이터만 읽고 쓰지는 않습니다. |

  자세한 내용은 [참조: 메타데이터 필드](/help/reference/reference-docs.md)를 참조하십시오.

### OpenAI 메타데이터

- **상태 텍스트 호출** - 작업이 실행되는 동안 LLM 플랫폼에 표시되는 메시지(최대 64자)입니다. 예: *제품 로드 중...*
- **상태 텍스트를 호출했습니다** - 작업이 완료된 후에 표시되는 메시지(최대 64자). 예: *로드된 제품.*

### 가시성 및 입력 매개 변수

**가시성**&#x200B;은(는) 작업을 사용할 수 있는 위치를 제어합니다.

- **AI 모델에 표시** — AI 모델에서 작업을 호출할 수 있습니다.
- **앱 표면에 위젯으로 표시** — 작업이 시각적 위젯을 렌더링합니다.

**입력 매개 변수**&#x200B;은(는) LLM 플랫폼에서 처리기로 보내는 값입니다. 이 모델은 사용자의 메시지에서 자동으로 이를 추출합니다. *제품 검색*&#x200B;의 경우 다음을 정의합니다.

- **category**(문자열, 선택 사항) - 결과 범위를 좁히기 위한 범주 필터(예: 제품 유형 또는 부서)입니다.
- **쿼리**(문자열, 선택 사항) — 자유 텍스트 검색어입니다.

각 매개 변수에는 **이름**, **유형**(문자열, 숫자, 정수, 부울), **설명** 및 **필수** 확인란이 있습니다. 매개 변수를 더 추가하려면 **+ 추가**&#x200B;를 클릭하십시오.

자세한 내용은 [참조: 작업 매개 변수](/help/reference/reference-docs.md)를 참조하십시오.

### 분석

![작업 만들기 — analytics 사용자 의도](/help/assets/guide-create-action/action-analytics-user-intent.png)

- **사용자 의도** — 활성화되면 [!DNL ChatGPT]에게 이 작업을 호출한 대화를 요약하도록 요청합니다. 해당 요약은 수집되고 Analytics에 표시되므로 insight에서 작업이 트리거될 때 사용자가 달성하려고 한 작업을 확인할 수 있습니다.

## 위젯 메타데이터 탭

이 탭은 작업의 시각적 응답이 LLM 플랫폼에서 렌더링되는 방법을 구성합니다. 위젯의 작동 방식에 대한 자세한 내용은 [안내서: 위젯(EDS) 설정](/help/guides/widgets.md)을 참조하십시오.

![작업 만들기 — 위젯 메타데이터](/help/assets/guide-create-action/widget-metadata.png)

### 위젯 정보

- **유형** — 위젯 기술(현재 **[!UICONTROL EDS]**).
- **위젯 도메인(샌드박스 원본)** - 위젯이 호스팅되는 원본. 앱을 OpenAI에 제출하는 데 필요합니다. 앱별로 고유해야 합니다.
- **테두리 선호** — 테두리 카드 내에서 위젯을 렌더링합니다.

### 템플릿 URL

- **[!UICONTROL 스크립트 URL]** — 모든 작업에서 공유되는 위젯을 부트스트랩하는 진입점입니다.
  `https://main--<repo>--<owner>.aem.live/scripts/aem-embed.js`
- **위젯 포함 URL** — 이 특정 작업의 EDS 페이지입니다.
  `https://main--<repo>--<owner>.aem.live/eds-widgets/<action-name>`

### 권한

위젯이 액세스할 수 있는 하드웨어 및 브라우저 API:

| 권한 | 설명 |
|-----------|-------------|
| **카메라** | 장치 카메라 액세스 |
| **마이크** | 장치 마이크 액세스 |
| **지리적 위치** | 사용자 위치 액세스 |
| **클립보드** | 클립보드에서 읽기 또는 쓰기 |

### CSP 구성

![작업 만들기 — 권한 및 CSP](/help/assets/guide-create-action/widget-permissions-csp.png)

위젯 iframe이 연결할 수 있는 외부 도메인을 제어합니다. 모든 외부 도메인은 명시적으로 허용 목록에추가된여야 합니다.

| 지침 | 설명 |
|-----------|-------------|
| **리소스 도메인** | 정적 에셋용 도메인 — 이미지, 글꼴, 스크립트, 스타일 |
| **도메인 연결** | `fetch`, `XHR` 또는 `WebSocket`을(를) 통해 위젯이 연결할 수 있는 도메인 |
| **프레임 도메인** | 중첩된 iframe에 허용된 원본. 항목을 추가하면 OpenAI에서 보다 엄격한 앱 검토를 트리거합니다. |
| **도메인 리디렉션** | `openExternal`개의 리디렉션 링크에 대한 신뢰할 수 있는 대상([!DNL ChatGPT]별) |
| **기본 URI 도메인** | `base-uri` CSP 지시문(MCP 앱 SDK 전용, [!DNL ChatGPT]에서 지원되지 않음) |

저장하려면 **새 작업 만들기**&#x200B;를 클릭하세요.

## 작업 생성 후

작업이 [작업] 페이지에 카드로 나타납니다.

![작업 페이지 — 작업 생성됨](/help/assets/guide-create-action/actions-with-action.png)

각 카드에는 작업 이름, 설명, 유형 배지(**[!UICONTROL EDS]**), 배포 상태(**배포되지 않음**) 및 매개 변수 수가 표시됩니다. **..**&#x200B;을(를) 클릭하여 편집하거나 삭제하거나 **검토**&#x200B;을(를) 클릭하여 구성을 검사할 수 있습니다.

![앱 세부 정보 — 배포되지 않음](/help/assets/guide-create-action/app-detail-not-deployed.png)

작업 메타데이터가 저장되지만 코드가 아직 배포되지 않았습니다. 작업을 제대로 수행하려면 다음을 수행해야 합니다.

1. **EDS 위젯 설정** — [안내서: EDS(위젯) 설정](/help/guides/widgets.md) 참조.
2. **처리기를 작성하십시오** — [안내서: 작업 처리기를 작성하십시오](/help/guides/write-action-handler.md).
3. **[!UICONTROL 배포]** — [안내서: 앱 배포](/help/guides/deploy-your-app.md)를 참조하십시오.
